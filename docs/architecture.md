# ADR-001: общая реализация в системном WebView

Дата: 2026-11-17. Статус: принято для предварительного MVP; магазинный релиз и ресурсные бюджеты не утверждены.

## Решение

JavaScript/ES modules + Vite + Capacitor 8.6.2, один интерфейс без React/Vue, нативные оболочки Android/iOS. Android 10+ с обновлённым WebView; iOS 17.4+ как целевая матрица. PDF.js legacy build содержит полифиллы для части новых JavaScript API.

Первоначальный план SwiftUI + Compose был гипотезой. Для MVP выбран общий код: четыре формата и шрифты проверяются одинаковыми сценариями, исходники воспроизводимо собираются на доступной машине. Нативная оболочка использует установленный системный WebView, не включает Electron/Chromium.

Это не доказательство, что WebView экономнее нативного рендера. Решение пересматривается, если реальные замеры LR-020 не укладываются в бюджеты. Flutter и KMP пока не прототипировались: сравнительные результаты не выдуманы.

## Компоненты

| Задача | Реализация |
| --- | --- |
| UI | обычные DOM/CSS, мобильная компоновка, нативный диалог выбора файлов |
| EPUB/FB2 | Foliate JS, закреплённый commit в vendor/README.md |
| ZIP | zip.js с чтением диапазонов, проверкой размеров/путей |
| PDF | PDF.js 6.5.438, отдельный worker и диапазонный источник |
| DjVu | актуальный DjVu.js GPL-2.0-or-later, отдельный worker |
| Библиотека | IndexedDB v2: books/files/chunks/fonts/settings |
| Android «Открыть в…» | LeafInboxPlugin + Intent VIEW/SEND |
| iOS «Открыть в…» | SceneDelegate + LeafInboxPlugin |

Список метаданных не подгружает оригиналы книг. Исходники хранятся фрагментами по 1 MiB; метаданные становятся видимыми только после завершения записи. Незавершённые фрагменты очищаются при следующем запуске. Обёртка StoredFile предоставляет slice/stream/arrayBuffer; EPUB/PDF получают нужные диапазоны с кешем максимум двух фрагментов. FB2 целиком преобразуется в секции; DjVu целиком передаётся в worker с transfer без дополнительного копирования.

Двоичные шрифты подгружаются при выборе, список отображает метаданные. Обложки уменьшаются перед сохранением. File/Blob не записываются в IndexedDB: тестовый WebKit на Windows не поддерживал этот сценарий корректно; двоичные данные сохраняются ArrayBuffer.

## Контракт чтения

Текстовый адаптер возвращает sections, metadata, toc, rendition и destroy; foliate-view даёт goTo/prev/next/search/close. Растровый адаптер возвращает count, toc, render(page, canvas, width, zoom), close. Интерфейс скрывает типографику и текстовый поиск для fixed layout. CFI используется для текстового места; номер страницы — для PDF/DjVu. Прогресс не заменяет locator.

При выходе сохранение завершается до возвращения в библиотеку. Обновления позиции при чтении объединяются с задержкой 500 мс. При аварийном завершении процесса последняя такая порция может быть потеряна. Рендереры/worker и временные URL освобождаются при закрытии.

## Границы безопасности

Проверяются сигнатура и расширение, общий размер, размеры ресурсов и фактическая распаковка ZIP. Запрещены traversal, повторные пути, зашифрованные архивные записи, DTD с сущностями, скрипты/обработчики событий/iframe/form/object в EPUB. CSP ограничивает ресурсы приложения; внешние ссылки книг не открываются автоматически.

Импорт из внешнего приложения сначала копирует файл в приватный inbox с лимитом; JS подтверждает обработку, затем временная копия удаляется. Нативные обработчики требуют проверки на телефонах.

## Отложено

Потоковый FB2, фрагментный рендер огромных DjVu-страниц, сохранение положения внутри увеличенной PDF/DjVu-страницы, отмена длительного импорта из UI, отдельная сетевая политика для внешних ссылок по согласию, полная английская локализация и ручной аудит скринридеров. Нельзя считать эти первоначальные критерии уже выполненными.
