# Проверка предварительного MVP

Дата: 2026-11-17. Среда: Windows, Node.js 24.14.1; Chromium и WebKit из Playwright 1.65.1. WebKit здесь — тестовый порт, а не физический iPhone.

## Выполнено

- Модульные проверки: пути и лимиты ZIP, шрифтовые таблицы, запрет XML entities, лимит пикселей и идентичность файлов.
- Браузерные сценарии для всех четырёх форматов; PDF/DjVu проверяются по пикселям canvas, включая single/bundled DjVu.
- EPUB fixed layout, оглавление и поиск; FB2 с кириллицей, Windows-1251 и буквой Ё.
- Импорт TTF и OTF, применение, сохранение выбора после перезапуска, удаление с fallback.
- Закладки, повторное открытие, дубликаты, удаление, темы, мобильная ширина 390 px.
- Небезопасный EPUB: код не исполняется, внешние картинки не запрашиваются.
- Чтение EPUB, пересекающего несколько сохранённых фрагментов, после повторного открытия.
- Финальный Android assembleDebug завершился успешно; подпись APK проверена. APK: 12546399 bytes (≈11.97 MiB). Веб-ресурсы: 5799115 bytes. Модульные тесты: 5/5; сценарии: 24/24 (12 Chromium + 12 WebKit).

Последний полный запуск и контрольные суммы поставки находятся в outputs/verification.txt. CI описан, но не запускался удалённо.

## Что не подтверждено

- Сборка Xcode и запуск на iPhone: в этой среде нет macOS/Xcode.
- Установка/работа на реальных Android, системный Share/Open-in, поворот и фон на телефонах.
- VoiceOver/TalkBack, полноценный английский интерфейс и все состояния доступности.
- Большой корпус сторонних книг, сложные сноски/таблицы/шрифты, зашифрованные PDF, смешанная вёрстка.
- Память, батарея, нагрев, p95 и библиотека из 1 000 книг на эталонных телефонах.
- Публичная публикация, полный пакет соответствующих исходников всех нативных зависимостей, условия App Store.

## Ограничения

Книга ≤128 MiB, FB2 ≤24 MiB, шрифт ≤12 MiB; DjVu-страница ≤16 MP. Для PDF и EPUB работает диапазонное чтение из хранилища; DjVu получает весь исходный буфер, FB2 разбирается целиком. Эти лимиты обеспечивают контролируемый отказ, но не доказывают выполнение исходных ресурсных бюджетов.

Сохранение мест PDF/DjVu пока на уровне страницы, без восстановления zoom/pan. Нет OCR, DRM, sync, FB2 ZIP, indirect DjVu. Веб-предпросмотр не является PWA. Хранилище локально; удаление приложения/данных браузера удаляет библиотеку.

Поэтому LR-021 остаётся незавершённой: работающий кандидат MVP нельзя приравнять к принятому релизу на двух платформах.
