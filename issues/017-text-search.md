# LR-017 — Добавить поиск внутри FB2 и reflow EPUB

- **Статус:** in-progress
- **Приоритет:** P1
- **Этап:** M2
- **Зависимости:** [LR-010](010-fb2-reader.md), [LR-011](011-epub-reader.md), [LR-015](015-reading-controls.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Позволить быстро найти текст и вернуться к чтению.

## Объём работ

- Искать по тексту всей книги с кириллицей и без учёта регистра.
- Показывать контекст совпадения, переход и возврат.
- Индексировать лениво, с лимитом диска, отменой и без блокировки интерфейса.

## Критерии готовности

- [ ] Совпадения находятся в разных главах обеих форматов на двух платформах.
- [ ] Пустой запрос, отсутствие совпадений и изменение запроса обработаны.
- [ ] Отмена поиска останавливает ненужную работу; большой текст не вызывает скачка памяти.
- [ ] Поиск по сканам и OCR не заявлены как реализованные.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
