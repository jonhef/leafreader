# LR-015 — Реализовать экран чтения и настройки

- **Статус:** in-progress
- **Приоритет:** P1
- **Этап:** M2
- **Зависимости:** [LR-004](004-mobile-design.md), [LR-008](008-reader-contract.md), [LR-010](010-fb2-reader.md), [LR-011](011-epub-reader.md), [LR-012](012-pdf-reader.md), [LR-013](013-djvu-reader.md), [LR-014](014-custom-fonts.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Объединить движки в единый удобный сценарий чтения.

## Объём работ

- Добавить скрываемые панели, оглавление, прогресс и переходы.
- Для reflow — размер шрифта, поля, интервал, листание/прокрутка и темы.
- Для fixed layout — масштаб и подгонка; темы UI не должны делать страницу нечитаемой.
- Хранить общие настройки с переопределениями для книги и сбросом.

## Критерии готовности

- [ ] Все четыре формата управляются через общий экран на двух платформах.
- [ ] Настройки применяются без потери позиции; доступны только подходящие возможности.
- [ ] Поворот экрана, фон/возврат и системное масштабирование UI не ломают управление.
- [ ] Светлая, тёмная и сепия-темы проверены по контрасту и читаемости.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
