# LR-024 — Спроектировать необязательное резервирование и синхронизацию

- **Статус:** open
- **Приоритет:** P2
- **Этап:** После MVP
- **Зависимости:** [LR-021](021-release-mvp.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Сохранять библиотеку и прогресс между устройствами без обязательного аккаунта.

## Объём работ

- Уточнить сценарии ручного экспорта и опционального облака.
- Проработать конфликты прогресса, перенос шрифтов, приватность и расход батареи.
- Оценить стоимость и влияние SDK до реализации.

## Критерии готовности

- [ ] Есть отдельное решение о модели данных, конфликтах и провайдере; синхронизация по умолчанию выключена.
- [ ] Офлайн-чтение полностью работает без аккаунта.
- [ ] План содержит восстановление после сбоя и квоты; реализации предшествует подтверждение объёма функции.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
