# LR-023 — Добавить текстовый поиск PDF/DjVu и заметки

- **Статус:** open
- **Приоритет:** P2
- **Этап:** После MVP
- **Зависимости:** [LR-021](021-release-mvp.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Расширить навигацию там, где в документе есть текстовый слой.

## Объём работ

- Исследовать извлечение текста PDF/DjVu, координаты совпадений и возможности выделения.
- Добавить цитаты/заметки с устойчивыми якорями там, где позволяет формат.
- Предусмотреть экспорт заметок и понятное поведение сканов.

## Критерии готовности

- [ ] Поиск работает по существующему текстовому слою и ведёт к странице/совпадению.
- [ ] Скан без текста не выдаёт ложного обещания поиска; OCR требует отдельной задачи.
- [ ] Заметки сохраняются и экспортируются; смена шрифта не ломает якоря reflow.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
