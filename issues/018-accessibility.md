# LR-018 — Проверить доступность и локализацию интерфейса

- **Статус:** open
- **Приоритет:** P1
- **Этап:** M3
- **Зависимости:** [LR-009](009-library-ui.md), [LR-015](015-reading-controls.md), [LR-016](016-progress-bookmarks.md), [LR-017](017-text-search.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Сделать интерфейс пригодным для VoiceOver/TalkBack и крупного текста.

## Объём работ

- Добавить семантические подписи, порядок фокуса и доступное управление.
- Проверить контраст тем, reduced motion и увеличенный системный текст.
- Вынести строки; добавить русский и английский интерфейс как начальную пару.

## Критерии готовности

- [ ] Импорт, открытие, настройки и закладки проходятся с VoiceOver/TalkBack.
- [ ] Нет обрезанных действий при крупном тексте и длинных переводах.
- [ ] Отсутствие текстового слоя в скане честно обозначено; OCR не имитируется.
- [ ] Отчёт содержит ручные проверки обеих платформ и исправленные проблемы.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
