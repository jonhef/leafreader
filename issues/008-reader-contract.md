# LR-008 — Определить контракт адаптеров чтения

- **Статус:** in-progress
- **Приоритет:** P0
- **Этап:** M1
- **Зависимости:** [LR-005](005-mobile-bootstrap.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Дать интерфейсу единый способ работать с разными форматами без потери их возможностей.

## Объём работ

- Определить операции открытия, метаданных, оглавления, перехода, позиции и закрытия.
- Добавить capabilities для шрифтов, reflow, поиска и фиксированных страниц.
- Определить ошибки, отмену, жизненный цикл и форматные locator с версией.

## Критерии готовности

- [ ] Контракт описан и реализован в выбранном стеке; UI не зависит от конкретного декодера.
- [ ] Закрытие отменяет работу и освобождает ресурсы; устаревший результат не обновляет новую книгу.
- [ ] Неподдерживаемые действия скрываются или объясняются, не вызывая сбой.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
