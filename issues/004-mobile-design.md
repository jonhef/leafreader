# LR-004 — Спроектировать мобильный интерфейс по мотивам Thorium

- **Статус:** open
- **Приоритет:** P1
- **Этап:** M0
- **Зависимости:** нет
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Получить согласованный набор экранов для телефона и управления одной рукой.

## Объём работ

- Подготовить макеты библиотеки, чтения, содержания, настроек и импорта шрифтов.
- Задать цвета, типографику, размеры зон нажатия и состояния из docs/design.md.
- Продумать reflow и fixed layout, доступность, тёмную тему и длинные названия.

## Критерии готовности

- [ ] Есть макеты всех обязательных экранов для iPhone и Android, включая пустые состояния и ошибки.
- [ ] На макетах показаны путь импорта книги, смена шрифта и возвращение к месту чтения.
- [ ] Используются собственные ассеты; элементы доступны при увеличении системного текста.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
