# LR-009 — Реализовать библиотеку и «Продолжить чтение»

- **Статус:** in-progress
- **Приоритет:** P1
- **Этап:** M1
- **Зависимости:** [LR-004](004-mobile-design.md), [LR-006](006-library-storage.md), [LR-007](007-file-import.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Сделать локальную коллекцию удобной даже при большом числе книг.

## Объём работ

- Добавить обложки/список, сортировку, поиск по названию и автору.
- Показывать последнюю книгу и прогресс, карточку метаданных и удаление.
- Миниатюры генерировать лениво с ограниченным кешем.

## Критерии готовности

- [ ] Поиск и сортировка работают на 1 000 записей без блокировки UI.
- [ ] Пустые, ошибочные и загрузочные состояния соответствуют макетам.
- [ ] Удаление требует подтверждения и освобождает связанные данные, не затрагивая исходник вне приложения.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
