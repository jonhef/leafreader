# LR-012 — Реализовать постраничное чтение PDF

- **Статус:** in-progress
- **Приоритет:** P0
- **Этап:** M2
- **Зависимости:** [LR-002](002-engine-feasibility.md), [LR-007](007-file-import.md), [LR-008](008-reader-contract.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Читать текстовые PDF и сканы с ограниченным расходом памяти.

## Объём работ

- Добавить выбранный движок, переход по номеру и оглавление при наличии.
- Реализовать pinch zoom, перемещение, подгонку ширины/страницы.
- Ограничить растровый кеш и отменять ненужный рендер.

## Критерии готовности

- [ ] Многостраничные, повёрнутые страницы и сканы отображаются корректно на обеих платформах.
- [ ] Документ на 1 000 страниц не рендерится целиком; память укладывается в принятый бюджет.
- [ ] Повреждённый и защищённый паролем PDF дают понятный результат без падения.
- [ ] Настройки текстового шрифта не предлагаются для страницы PDF.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
