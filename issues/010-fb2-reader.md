# LR-010 — Реализовать чтение FB2

- **Статус:** open
- **Приоритет:** P0
- **Этап:** M2
- **Зависимости:** [LR-002](002-engine-feasibility.md), [LR-007](007-file-import.md), [LR-008](008-reader-contract.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Поддержать FB2 с кириллицей, иллюстрациями и сносками.

## Объём работ

- Добавить потоковый XML-разбор и выбранное локальное представление.
- Сохранить главы, форматирование, стихотворения, изображения, сноски и метаданные.
- Поддержать UTF-8/Windows-1251 и устойчивые ID для мест чтения.

## Критерии готовности

- [ ] Тестовый корпус FB2 читается офлайн на обеих платформах; кириллица не повреждена.
- [ ] Оглавление и переход к сноске с возвратом работают.
- [ ] Большой документ не загружается целиком в память; лимиты входных данных применяются.
- [ ] Повреждённый XML и неизвестная кодировка дают понятную ошибку без потери библиотеки.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
