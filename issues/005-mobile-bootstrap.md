# LR-005 — Создать проекты iOS/Android и воспроизводимые сборки

- **Статус:** open
- **Приоритет:** P0
- **Этап:** M1
- **Зависимости:** [LR-003](003-architecture-decision.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Подготовить минимально работающие клиенты без лишних зависимостей.

## Объём работ

- Создать проекты и структуру модулей выбранного стека.
- Зафиксировать инструменты, lockfiles, форматирование и локальные команды.
- Добавить CI для сборки и существенных проверок обеих платформ.

## Критерии готовности

- [ ] Оба приложения собираются из чистого checkout по инструкции.
- [ ] В CI проверяются Android и iOS на подходящих runners; секреты не коммитятся.
- [ ] Пустой экран запускается на устройствах; размер базовой release-сборки записан.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
