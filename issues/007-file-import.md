# LR-007 — Добавить импорт книг средствами iOS и Android

- **Статус:** open
- **Приоритет:** P0
- **Этап:** M1
- **Зависимости:** [LR-006](006-library-storage.md), [LR-008](008-reader-contract.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Позволить открыть собственный документ из файлов или другого приложения.

## Объём работ

- Добавить системный picker, share/open-in на iOS и соответствующие Android intents/SAF.
- Копировать выбранный файл в управляемое хранилище и распознавать содержимое.
- Обработать дубликаты, отмену, нехватку места, недоступный облачный файл и потерю доступа.

## Критерии готовности

- [ ] FB2, EPUB, PDF и DjVu импортируются на обеих платформах и доступны офлайн после перезапуска.
- [ ] Расширение сверяется с содержимым; повреждение и неподдерживаемый формат объясняются пользователю.
- [ ] Дубликат предлагает открыть существующую книгу; отмена/ошибка очищают временные данные.
- [ ] Системный оригинал не удаляется и не изменяется.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
