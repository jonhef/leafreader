# LR-013 — Реализовать чтение DjVu

- **Статус:** open
- **Приоритет:** P0
- **Этап:** M2
- **Зависимости:** [LR-002](002-engine-feasibility.md), [LR-007](007-file-import.md), [LR-008](008-reader-contract.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Обеспечить обязательную поддержку DjVu без внешней конвертации или сервера.

## Объём работ

- Интегрировать одобренный декодер с нативным управлением памятью.
- Поддержать single-page и bundled multipage DjVu, zoom и переход по странице.
- Добавить ограниченный кеш, отмену декодирования и описание неподдерживаемых indirect файлов.

## Критерии готовности

- [ ] Оба варианта DjVu открываются офлайн на физических iPhone и Android.
- [ ] Большой документ читается без декодирования всех страниц; память соответствует бюджету.
- [ ] Повреждённый файл не завершает приложение; indirect документ объясняется пользователю.
- [ ] Лицензионные условия выбранного движка соблюдены, обязательные уведомления включены.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
