# LR-002 — Проверить движки всех форматов и их лицензии

- **Статус:** in-progress
- **Приоритет:** P0
- **Этап:** M0
- **Зависимости:** [LR-001](001-devices-budgets.md)
- **Платформы:** iOS и Android
- **Ответственный:** не назначен

## Цель

Подтвердить техническую и лицензионную осуществимость четырёх форматов на двух платформах.

## Объём работ

- Составить матрицу кандидатов для EPUB, FB2, PDF и DjVu с версиями, лицензиями и зависимостями.
- Собрать минимальные прототипы чтения на iOS/Android; измерить добавку размера и память.
- Особенно проверить DjVu: декодирование, arm64, поддержка страниц и допустимость распространения через выбранные магазины.

## Критерии готовности

- [ ] Для каждого формата на обеих платформах открыт реальный тестовый документ; отчёт содержит результаты и ограничения.
- [ ] Выбран вариант DjVu с документированными условиями распространения либо явно зафиксирован блокер MVP.
- [ ] У каждого кандидата есть источник лицензии, обязательства и измеренный размер; GPL не считается автоматически покрытым MIT.
- [ ] Зависимости с неясными условиями не включены в распространяемые сборки.

## Проверка и результат

Приложить к задаче ссылки на изменения и результаты проверки критериев. Для исследовательской задачи — решение и измерения; для реализации — сценарии обеих платформ, существенные тесты и известные ограничения. Отмечать критерии после проверки.
